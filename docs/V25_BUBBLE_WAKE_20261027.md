| --- | --- | --- |
| 晨光吉他 | 吉他撥弦、分解和弦與回應旋律 | 94 BPM |
| 竹林笛語 | 竹笛音色、三拍呼吸與長短句 | 88 BPM |
| 雨窗爵士 | 電鋼琴、七和弦與輕刷鼓 | 76 BPM |

| 星露八音盒 | 晶亮八音盒與高低音回應 | 108 BPM |
| 極光合成 | 空氣感合成器與緩慢音色起伏 | 84 BPM |
| 晴日律動 | 撥奏、低音與輕鼓節奏 | 118 BPM |

八款各有中性、晴、雨、雪四種配器，共 32 個新 PCM16 單聲道循環，32,000 Hz；另有 32 個 44,100 Hz Ogg/Vorbis 備援。樂器名稱描述合成音色，並非宣稱真實樂器錄音。所有旋律、配器與音色合成均為新寫的生成程式，沒有取用他人歌曲。

新編曲仍搭配原有 14 種天氣聲景；霧、霾、沙塵等使用中性旋律加對應聲景，沒有有效天氣時只播放中性旋律。原有六款與個人音樂 URI 保留，既有鬧鐘選擇不自動改寫；新建鬧鐘預選晨光吉他。漸強、鬧鐘音量串流、循環與清理共用既有播放引擎。

原六款速度相近，並共用和弦伴奏。新增音色改變速度、拍型、和聲、句長、節奏和發聲包絡，不以調音高增加數量。重製方式見 `android-project/tools/compose_wake_palette.py`；一般 Android 建置直接使用已附音檔。

旋律設計參考 McFarlane 等人 2020 年的 N=50 自陳問卷研究：旋律性與較低自覺睡眠慣性相關，研究沒有證明某種聲音對所有人都有效。本包做了音檔完整性、峰值、RMS 與循環接點檢查；主觀好聽程度及實際喚醒效果仍需使用者聆聽與使用，不能把工程檢查視為臨床驗證。

來源：<https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0215788>

## 全域透明泡泡滑桿

共用 `GlassSlider` 改用低填色透明鏡片。頭部直接跟手，完整尾端以較慢彈簧跟隨，連接處會拉細；放開後回合。虹彩邊框與高光隨拖動位置變化，沒有大面積藍白色拖鈕填色。

每個滑桿只擷取自身底層軌道作折射，不取樣包含自己或整頁的祖先。維持上一輪防循環取樣與可見範圍裁切。縮減動態時取消水尾與形變；降低透明度時使用清楚的實色備援。

指標操作和無障礙 SetProgress 共用範圍與步進規則；非法數值備援、彈簧超越邊界、縮小版面及密度改變有純數值測試。另修正字體／粗細滑桿忽略實際值標籤的問題，避免把正規化位置誤顯示成設定值。

## 天氣頁統一玻璃底色

一般方塊採共同色板：日間霧藍、夜間深藍，搭配白色主字與淺色次字。現在最重要的天氣、今天出門、天氣光景、24 小時預報、雷達、六個指標與空氣品質等共用底色，消除黑／白卡片混搭。降低透明度設定會把一般卡片改成相同色系的實色。

官方颱風警報、氣象特報與地震報告保留紅色；普通颱風入口與定位狀態使用一般色板。圖表、真實雷達影像與數值狀態色仍表達原有資料。一般卡片與警報的主字、次字在白、黑及明亮天空背景上的對比均須至少 4.5:1。
