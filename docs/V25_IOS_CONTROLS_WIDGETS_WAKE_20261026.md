## 使用與外觀

- 事項：新增事項 → 日期或時間列 → 共用滾輪 → 右上勾選；左上關閉或向下拖把手會取消草稿。
- 鬧鐘：編輯鬧鐘的時分與延遲響鬧時間使用同一滾輪。六款新鈴聲直接對應原有 ID，不須重建鬧鐘。點選鈴聲可試聽 12 秒。
- 設定 → 小工具與動態島：控制桌面圖示動態、資料時間、事項顯示及超級島天氣細節，也可同步桌面資料。
- 桌面長按加入小工具，調整尺寸會改變資訊密度。快取及過期狀態會明確標示；下一個鬧鐘／事項來自使用者儲存資料。
- 延續移除自然語言天氣播報的要求；新鬧鐘以旋律與天氣聲景播放，不重新開啟天氣 TTS。地震原有警示及演練流程保持。

## 聲音研究與設計判斷

McFarlane 等人的 PLOS ONE 研究為 50 人線上問卷，發現自評的旋律性與較低睡眠慣性感受有關；它並未證實某一首音樂或一個 BPM 能保證叫醒所有人。本包以此作設計參考，不宣稱臨床驗證、專業聽感驗收或喚醒成功率。

| 主題 | 編曲主體 | 基準速度（設計選擇） |
| --- | --- | --- |
| 晨光序曲 | 柔和鋼琴、上行旋律與暖和弦 | 104 BPM |
| 雨光節拍 | 柔鋼琴、清楚節拍與回應句 | 102 BPM |
| 森間晨行 | 木琴與輕撥弦 | 108 BPM |
| 水漣初醒 | 豎琴式撥弦與水紋旋律 | 106 BPM |
| 晴日躍動 | 較鮮明的撥弦與節拍 | 112 BPM |
| 霜光鈴奏 | 柔亮鐘琴與和聲回應 | 110 BPM |

天氣編曲改變速度、亮度及局部聲部；環境音另層播放。雷雨的環境聲音量較低，保留旋律辨識度，不以貼近耳邊的爆裂雷聲喚醒。起始音量包絡約 18 秒漸強，之後使用小幅的音量輪廓；實際聲壓仍由手機鬧鐘音量與喇叭決定。

音樂為此工程原創合成編曲，程式在 `android-project/tools/compose_weather_alarm_suite.py`。雨聲沿用專案原有素材及來源文件 `docs/WEATHER_AUDIO_SOURCES.md`；其他聲景為程序合成，不冒稱現場錄音。循環接縫、峰值、非靜音與檔案雜湊有數值檢查，不能代替人耳試聽。

## 平台與驗證界線

- Android App 使用自製 iOS 風格控制及既有 RuntimeShader 光學實作；這不是 Apple 私有引擎移植，也沒有把「100% 相同」當成已驗證結論。
- App 的 120 Hz 請求保留；桌面與小米 SystemUI 的刷新率、動畫、是否展開及允許的場景由系統管理。
- 桌面小工具不能任意取樣桌布作即時折射，採原創光學底圖、向量圖示及桌面端原生動畫。省電、減少動態效果或不支援的桌面可使用靜態圖示。
- 小米仍可能要求焦點通知的 App／場景授權；不繞過白名單。缺少支援時通知、鬧鐘音訊及鎖屏響鈴功能保留。
- 本次本機產生 unsigned Release；正式 OTA 沿用使用者 GitHub 原簽章。沒有自行發布本次 OTA，也沒有改寫全部 22 項人工驗收狀態。
- 手機 GPU、觸覺、桌面相容性、鎖屏／重開機與真實覆蓋安裝仍需手機驗證。建置、單元測試與靜態檢查不等於所有硬體行為已驗收。
