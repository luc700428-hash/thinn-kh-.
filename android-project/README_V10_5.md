# thinn-khì V10.5 — 定位與互動預報

這是可由 GitHub Actions 嘗試建置的 Android 原始碼，**不是已完成實機驗證的 APK**。

## 真正修改的檔案

- `presentation/home/InteractiveForecast.kt`：24 小時水平捲動的逐時溫度曲線；每小時天氣圖示、風速（m/s）與時間對齊；選取時段讀值；拖動微震；日出／日落標記。
- `presentation/home/WeatherGauges.kt`：六張氣象卡（紫外線、濕度、體感、風向、氣壓、日出日落），長按跟手拖動、釋放回彈、重排保存。
- `presentation/home/WeatherHomeScreen.kt`：接通日出／日落時間軸、取消獨立氣壓與日出方塊、縮短微縮城市與下面卡片的間距。
- `res/mipmap-*`：原創簡約雲朵、日光與氣流 App Icon，各解析度完整替換。

## 保留 V10.4 既有的功能

- GPS 定位進度狀態、成功／失敗提示，按下「回到目前 GPS 位置」不會在定位完成前關閉地點選單。
- 中央氣象署官方 RSS 的在地公告比對及「目前未找到所在地相關的最新特報公告」狀態，查詢失敗不假裝沒有警報。
- Xiaomi HyperOS 焦點通知／超級島附加欄位、權限檢查與標準 Android 通知回退。
- 環境部 AQI 最近測站查詢（需要 API Key）；無金鑰時顯示無資料，不把美制 AQI 當成台灣 AQI。

## 仍未完成

- 22 縣市**各自精細還原**的 3D 等距城市模型。目前是區域區分的程序化 3D/2.5D 原型，不應把它宣稱為正式高精細建築模型。
- 中央氣象署涵蓋所有災害類型的**即時**、有效範圍可驗證的告警 API。RSS 不是完整警報有效清單；WorkManager 的最短 15 分鐘週期也不是秒級推播。
- 最新 App 全面 Android 編譯、各廠手機的震動、手勢、焦點通知實機驗證。

## 設計注意事項

小米天氣的視覺結構可作互動參考，並非直接複製其專有素材或原始程式；App Icon 是原創圖示。
