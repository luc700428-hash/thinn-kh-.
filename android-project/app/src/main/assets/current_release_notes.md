# thinn-khì · 清晰雷達、連動黑色模式與 144Hz

<!-- THINN_INCREMENTAL_CHANGES -->
- 雷達底圖與回波分別縮放，放大時載入更細的地圖圖磚，可查看街道層級的地理資訊；回波改用 512 像素圖磚。
- 回波超過來源原始解析度時，保留觀測格點與強度顏色，並顯示細節上限提示，不把插值當成新增降雨資訊。
- 雷達底圖、背景與操作介面跟隨 App 明亮、黑色與系統自動模式切換，保留原有位置、縮放及歷史時間軸。黑色模式只改底圖配色，回波雨量顏色維持一致。
- 全 App 更新率目標提升至 144Hz，涵蓋主頁、地震、工具、設定、鬧鐘、對話框、抽屜、彈出選單及獨立 3D 繪圖表面；不更改螢幕解析度。
- 裝置不支援 144Hz 時使用可用更新率；診斷資訊區分請求目標與系統回報值，不冒稱實際 FPS。省電、溫控及桌面程式仍由系統控制。
- 底圖與回波獨立載入，切換歷史回波時保留底圖快取；播放會等待當前回波載入，重試可重新載入失敗圖磚。
<!-- END_THINN_INCREMENTAL_CHANGES -->

144Hz 為相容裝置上的請求目標，實際更新率與幀率須實機確認。桌面小工具動畫由啟動器管理。雷達為歷史觀測，不是未來預測。

# thinn-khì · 地點搜尋、App 內雷達與 Q 版天氣夥伴

- 主頁改為長條搜尋列，移除上方健康檢查與重新整理按鈕，加入下拉更新、進度光環與放手回彈。
- 城市搜尋加入台灣 368 個鄉鎮市區離線索引、英文別名、最近查看、常用地點、座標查詢及地區篩選；釣魚台使用「台灣」顯示。
- 降雨雷達改為 App 內原生地圖，可雙指縮放、拖曳、定位城市、播放歷史回波及調整透明度；保留圖層時間、載入失敗提示與來源標示。
- 天氣提示依資料代碼區分毛毛雨、小雨、中雨、大雨、短暫雨、雪、霧與雷雨，不以降雨機率推測雨勢。
- 晴天、多雲及夜晚使用一致的環境音播放器，加入原創鳥鳴、風聲、葉聲與蟲鳴循環，前景播放並配合媒體音量。
- 新增 Q 版天氣夥伴小工具，共 28 款。太陽、月亮、雲與雨雲依天氣變換，加入漂浮、呼吸光、眨眼、視線與雨滴落地水花；每次更新變換動作種子。
- 主 Dock 水尾更黏稠，地震「綜合／測站／震央」共用相同可拖曳液態玻璃與彩色邊光。
- 滑桿改用單一畫布，移除拖曳中的玻璃捕捉與可變濾鏡；字體大小與粗細接到共用文字層，修正巢狀主題重複縮放。字體滑桿放手後套用，避免拖曳時版面反覆變形。
<!-- END_PREVIOUS_CITIES_INCREMENTAL_CHANGES -->

小工具動畫由桌面程式管理，減少動態效果、關閉系統動畫及省電模式會使用靜態角色。手機相容性與起床效果仍需實機驗證。
