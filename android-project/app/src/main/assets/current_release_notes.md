# thinn-khì · 淺色主題、液態導覽與天氣碰撞

<!-- THINN_INCREMENTAL_CHANGES -->
- 新增 12 組淺色系主題與正方形色票，預設薄荷綠；背景、文字、控制項與小工具同步調整。
- 換色加入連續過渡，快速切換會由畫面當下顏色接續；保留減少動態效果與既有外觀選擇。
- Dock 改為透明膠囊滑片，整合觸碰伸縮、黏滯拖曳、回彈、背景模糊與邊緣折射。
- App 圖示、啟動標誌與內部 Logo 調為更淺的綠色；啟動底色配合系統明暗，並調整文字與按鈕對比。
- 移除「現在的天氣」外層方塊，保留溫度與天氣資訊；雨滴可與溫度字形碰撞、附著並滑落。
- 天氣動畫依資料細分毛毛雨、小雨、中雨、大雨與雷雨，並區分早晨、白天、傍晚及夜間背景。
- 溫度、高低溫、颱風資訊及警報等實際物體接入碰撞場景，雨滴、飛濺、積雪與滑動時的散落會跟隨物體位置。
- 新增小雪、中雪、大雪的堆積與散落，強風中的落葉可碰撞、短暫停留並隨風擺動後吹離；無雨的強風情境不會自行加入降雨。
- 雷雨可出現隨機落雷、卡片角落的短暫裂紋與焦痕視覺，並尊重減少動態效果。
- 時鐘小工具（含 Q 版）加入會自動更新的月日日期，並重新配置小尺寸與大字體下的空間。
- 更新頁只顯示目標版本的更新內容，不再累加過去版本的特性清單。
<!-- END_THINN_INCREMENTAL_CHANGES -->

天氣動效為依資料驅動的視覺模擬，並非即時落雷或風場觀測。官方警報、雷達回波與地震震度保留資料原色。

沿用既有 APK 簽章與版本驗證。地震與颱風警報請以中央氣象署官方資訊為準。

動效與桌面更新由系統與桌面程式管理，實際呈現需實機驗證。
