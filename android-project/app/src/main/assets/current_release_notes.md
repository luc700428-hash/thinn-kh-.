# thinn-khì｜天氣首頁與在地微縮地標改版

本版本整合此前累積的 Android 介面與功能候選修正，以實際 GitHub 追蹤的 Kotlin 專案重新建置，不再透過固定的舊原始碼 ZIP 發版。

- 將原先「穿搭」長文改為精簡但保留重要資訊的「今天出門」卡片，技術計算資料移至次級畫面。
- 首頁重要天氣資訊直接顯示：體感、未來六小時降雨、氣溫變化、風速、濕度／空氣品質，以及簡明穿搭、雨具提醒。
- 修正臺灣縣市名稱下，中央氣象署特報入口可能被忽略的問題。
- 放大關鍵文字，統一 Liquid Glass 介面基礎、設定與常用操作控制。
- 已加入部分可辨識的獨立 GLB 原型，但首頁目前仍以 GLB 對應的靜態預覽圖顯示，不宣稱即時 3D 已完成。
- 在地微縮地標：依城市／部分島嶼資料挑選，顯示「縣市、地標名稱」，並提供模型原型預覽和切換。
- 我的事項與提醒、更新中心和公開 GitHub OTA 版本資訊的程式修正納入本次建置。
- GitHub Actions 不再讀取舊版原始碼 ZIP；更新中心顯示編譯時的來源 commit 識別碼，CI 校驗 APK 所含程式來源指紋。

已知限制：微縮地標目前仍是原創示意 GLB 與靜態預覽，不是全臺高精度即時 3D；部分衛星／地震等外部來源、低階裝置效能和所有頁面動作仍需實機驗證。請勿將測試／原型內容誤認為官方即時警報。
