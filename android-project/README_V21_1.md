# thinn-khì V21.1 — 智慧生活穿搭與免費開源 AI 整合

- 首頁新增上衣、褲子、外搭、鞋子、雨傘／雨衣五欄建議；採氣溫／體感／即時降雨／六小時降雨機率／風速／UV 推導，不會虛構預報。
- 提供「日常、步行、機車、戶外」四種情境，偏好會記住；機車優先建議長褲與合身雨衣。
- 資料過舊（2 小時）或離線快取時，醒目警告且停用 AI 生成。
- 可選用使用者自行架設的開源 AI 服務：Ollama `POST /api/generate` 與 Qwen2.5 1.5B（Apache 2.0）。
- 出於使用者隱私，AI **預設關閉**；僅點擊產生時透過 HTTPS 將匿名天氣數值與情境送往自選伺服器。無帳號、GPS 座標、城市名稱傳送。
- 未設定 AI 或服務失敗時，本機規則仍完整可用。AI 只負責補充自然語言，絕不決定災防警報。
- 保留 V21.0 原有地震監測、四分頁、Widgets、OTA、Liquid Glass 與官方資料警示。

## 前置條件

開源模型不內嵌 APK；使用者需在自己的電腦／伺服器部署 Ollama、執行 `ollama pull qwen2.5:1.5b`，並以可信任的 HTTPS 反向代理公開服務給手機。**不接受 HTTP**，也不宣稱可以免費使用未知第三方公開 API。API 文件：https://docs.ollama.com/api/generate

## 編譯與上架限制

目前交付的是 GitHub Actions 可建置的原始碼，不是已簽名可安裝的 APK；需先成功編譯並在真機測試、簽章及通過平台審核。天氣 Open-Meteo 模型資料不是中央氣象署官方實測警報。
