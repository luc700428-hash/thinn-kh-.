# thinn-khì V11.2 通知聲音調整 — 清鈴 (Clear Bell)

- 原本 1.42 秒的「微光」上行和弦更新為約 0.66 秒的「清鈴」雙聲提示音。
- 聲音更清楚、更短、更乾淨，沒有延長的泛音背景；附上 3 種音效試聽檔，其中 A 清鈴是預設通知音。
- 天氣警特報、版本更新與測試通知會使用統一新聲音，但維持個別 Android 通知類別。
- Android 8.0+ 的通知通道首次建立後聲音不可直接修改，所以升級為 v2 通道 ID。
- 使用者可以在系統通知設定重新選擇／關閉聲音；APP 不能繞過靜音、勿擾或手機廠牌限制。
- 仍保留原始 V11.1 版本中所有天氣、光效、地標、Widget、OTA 與 Xiaomi 焦點通知的支援邏輯。
