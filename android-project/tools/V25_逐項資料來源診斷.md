# thinn-khì V25｜逐項資料來源驗收（不代表已實機通過）

## 實測路徑

在實際安裝的候選版中：設定 → 權限與健康檢查。

1. 點選「測試臺北天氣網路連線」：固定以臺北測試，不使用個人定位；即使拿到快取，也不得當成網路成功。
2. 點選「測試 CWA 官方資料代理」：僅檢查一種地震報告資料的 Firebase 代理回應；不是地震即時警報驗收。
3. 點選「測試 CWA 颱風官方路徑」：要求官方 normalized TropicalCyclones 結構；沒有活動颱風或沒有路徑時可視為資料代理成功，但不等於有颱風預報。
4. 額外實機檢查手機定位、雷達底圖、地震 SSE、FCM 推播、超級島、鬧鐘、語音、Widget 與舊資料保存。

## 分類規則

- NETWORK_FRESH：網路提供且快取／過期旗標皆為否，抓取時間在合理範圍內。**只證明該次天氣請求**。
- CACHED：只拿到快取或過期資料，不可標成「即時連線成功」。
- INVALID_TIME：取得資料，但抓取時間不合理。
- 颱風沒有可顯示路徑：區分「官方 JSON 正常回覆」與「無路徑」，不虛構颱風與警報。

## 尚未驗證的發布前阻擋項

Firebase 雲端函式部署、CWA 會員授權碼、地震 FCM 端到端、Google Weather Lab 正式授權資料取得、雙機型 Android 16 測試、全 App 「哪來哪去」動畫與鬧鐘實際準時性都需獨立實機證據。

本補丁不變更 `next_release_gate.json` 任何 status，不觸發 OTA，不啟動正式地震通知。
