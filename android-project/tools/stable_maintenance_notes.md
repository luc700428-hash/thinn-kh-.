# thinn-khì V25 · 正式維護更新

此更新將目前已成功編譯的 V25 程式整合成果提供給既有使用者，**不是「全部 22 項 V25 功能已完成」的宣告**。部分完整功能及實機驗證仍在進行。

這次正式維護更新採用原有的 Android 套件名稱與發版簽章，版本號遞增，並在正式發佈前檢查原始碼版本、APK 可編譯性、測試、舊版安裝簽章相符、套件識別、APK SHA-256 及更新描述檔。

使用者在 App 內開啟「系統更新」，可以檢查與下載本次正式更新；安裝須由 Android 系統及使用者同意，不會在背景靜默安裝。

**仍有限制**：小米超級島顯示取決於 HyperOS 授權；Google Weather Lab 路徑目前為本機 CSV 對照；桌面小工具不提供 Android 系統不允許的持續背景動畫。若遇到真實地震警報或颱風警戒，請以中央氣象署官方資訊為準。

這次更新沒有將任何未完成的 22 項 V25 功能虛構成已驗收；完整 V25 正式驗收仍另外保留。
