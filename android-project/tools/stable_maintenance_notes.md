# thinn-khì · 液態 Dock、小工具縮放與對比修正

<!-- THINN_INCREMENTAL_CHANGES -->
- 修正手機、平板與不同 Dock 位置的選擇滑片尺寸及對齊；滑片涵蓋圖示與文字，以清楚的主題色及粗體標示目前頁面。
- Dock 加入即時背景模糊、獨立移動的折射滑片與彈性拖曳、黏滯尾端、放開回彈，並避免待機控制項持續播放裝飾動畫。
- 設定新增獨立「主題顏色」頁，以 12 組卡片與正方形色票選擇；點選預覽，右上角勾號確認，返回取消。換色動畫接續當下顏色，標誌維持薄荷綠。
- 修正深色頁面誤用淺色天氣底圖的問題，統一玻璃按鈕的文字及圖示前景，改善地震圖層、放大縮小及 Dock 的可辨識度。
- 滑桿恢復原本的圓角膠囊拖曳鈕，加入觸碰伸縮、彈性尾端、模糊與反射；開關與共用控制項同步改善玻璃材質。
- 將視窗、彈出頁面及支援的繪圖表面更新率目標提升至 166 Hz；依裝置實際支援模式選擇，維持原有解析度，並減少重複更新率請求。
- 雷電改為有分支的隨機路徑及不規則多次回擊，加入涵蓋整個天氣畫面的明暗變化；遵循減少動態效果設定。
- 落葉改用每片獨立的連續風擾，從碰撞附著點顫動、彎曲後吹離，減少同步規律擺盪。
- 閃光改為只更新繪製層，減少碰撞場景逐幀複製與控制項待機動畫，改善滑動及互動時的負擔。
- 桌面小工具的溫度、時間與文字會依可用尺寸放大；大型方形 Q 版小工具改為左右排列天氣與角色，並重新分配時鐘及日期空間。
- 地震圖層切換列改為取用地震頁自己的材質底色，避免帶入其他頁面的深色背景，改善淺色與深色模式的文字、圖示及選中對比。
- Dock 依淺、深色搭配材質底色與文字色，讓未選中的文字與圖示保持清楚，並保留背景透色；玻璃光效同步遵循減少動態效果設定。
- 外觀滑桿即時預覽，停止拖動後合併儲存，避免每一影格寫入設定；離開 App 時保留最後數值，並在背景更新小工具。
<!-- END_THINN_INCREMENTAL_CHANGES -->

更新頁只顯示目標版本內容。天氣動效為依資料驅動的視覺模擬，並非即時落雷或風場觀測；官方警報、雷達回波與地震震度保留資料原色。

166 Hz 為裝置支援時的更新率目標，實際更新率與動畫效能由硬體、系統及省電狀態決定，仍需實機驗證。動效與桌面更新由系統與桌面程式管理。

沿用既有 APK 簽章與版本驗證。地震與颱風警報請以中央氣象署官方資訊為準。
