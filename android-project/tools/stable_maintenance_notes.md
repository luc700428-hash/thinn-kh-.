# thinn-khì · 介面與可靠性更新

<!-- THINN_INCREMENTAL_CHANGES -->
- 底部 Dock 加入液態牽引、細頸拉伸、斷開與回彈，容器位置固定。
- 全站滑桿統一為細軌道、藍色進度與透明光學膠囊滑塊。
- 天氣卡片加入會聚合滑落的雨滴、碰撞飛濺，以及積雪與融雪。
- 颱風主圖與時間軸改用內建國土測繪中心向量底圖，支援平移與 32 倍縮放。
- 地震主頁重新排版，速報視窗採統一玻璃元件，保留來源、資料時效與演練標示。
- 工具與設定依用途分類，加入工具搜尋、碼錶與離線氣象單位換算。
- 移除自然語音設定與雲端播報，清理舊語音快取；鬧鐘及地震警示音保留。
- 軟體更新頁完整顯示目標版本的實際發行內容。
- 一般簽章 OTA 與全功能里程碑驗收分開判定，維持 APK 簽章、來源指紋、版本遞增及 SHA-256 檢查。
<!-- END_THINN_INCREMENTAL_CHANGES -->

安裝仍需透過 Android 系統安裝程式確認。地震與颱風警報請以中央氣象署官方資訊為準。
