# thinn-khì · 更新狀態、雨滴碰撞與玻璃光學

<!-- THINN_INCREMENTAL_CHANGES -->
- 修正已安裝新版後仍顯示同一版待安裝、版本箭頭重複及舊錯誤的問題；重新核對後顯示「已是最新版本」。
- App 主畫面、鬧鐘、抽屜與對話框統一請求 120 Hz，移除視覺動畫的 30 FPS／低頻計時器限制，保留裝置相容回退。
- 天氣雨效改用單一碰撞世界：雨點碰到實際卡片才反彈飛濺、積水合併、沿圓角與邊緣流動、形成水頸後滴落。
- 保留 14 類天氣背景、風向與雨勢差異、積雪與融雪；明確標示的演示與實際天氣使用同一套視覺材質。
- 修正淺色雷達／三小時預報卡片的白底白字問題，主要數值、次要資訊與警示文字使用可讀的對比色。
- 加強 Dock 選取膠囊的黏連錨點、液態橋與斷開回彈；光學焦點連續跟隨手指。
- Android 13 以上新增背景取樣折射、邊緣色散與反光 shader，圖示和文字保持清晰；舊系統保留毛玻璃回退。
- 颱風路徑增加方向箭頭、預報虛線及臺灣時間，支援分颱風檢視，時間軸改為保留返回位置的原生頁面轉場。
- 保留 APK 簽章、版本遞增、來源指紋與 SHA-256 驗證，沿用 GitHub 正式簽章發布。

螢幕更新率與實際 FPS 仍受裝置、溫控及省電設定影響。安裝由 Android 系統確認；地震與颱風警報請以中央氣象署官方資訊為準。
