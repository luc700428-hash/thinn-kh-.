# thinn-khì V25 — 地震推播同意與送達驗收

## 本次工程目標

修正 Firebase `subscribeToTopic` / `unsubscribeFromTopic` 非同步返回順序不固定時，舊操作覆蓋使用者最新開關選擇的問題。啟用中可直接改為關閉；本機通知閘門立即停止。上一筆舊回呼不可把已關閉的設定寫回啟用。

### 工程測試（GitHub CI）

- 新增六項 Kotlin 純規則測試（啟用、停用、舊回呼、反覆開關）。
- 新增四項 Python 原始碼回歸檢查。
- 舊有 Python/Node/Gradle 測試必須全部通過，且未修改 `main`。

### 實機仍必須測試（不得填寫 `verified`）

1. Xiaomi HyperOS 與 Samsung：啟用 → 立即停用 → 網路切換 → 確認 UI 仍為關閉、測試訊息不被當作正式警報。
2. Firebase：確認 Android Firebase 配置、匿名登入／Cloud Functions 部署、FCM 主題訂閱／取消訂閱均能實際完成；不得顯示 Token 或金鑰。
3. 由授權測試後端發出明確標註的 **測試** 推播，核對 FCM 能否送達；不得發送偽造的 EEW 正式警報。
4. 真實地震資料來源的地區、時效、報次去重及通知權限；Android 背景、鎖屏、省電和勿擾狀態。
5. 不支援 Xiaomi 焦點通知時維持 Android 通知；不能宣稱 SystemUI 動態島由第三方保證。

成功訂閱 FCM ≠ 已部署官方資料代理 ≠ 真正送達 ≠ 保證在地震前收到警報。完整 V25 OTA 仍被 22 項驗收證據阻擋。
