# 滑桿穩定性與地圖閱讀修正

基底：7c3be0fdc6d3cafd39c16108fc2413db6e3eb0c9（第 307、308 次建置通過）。

共用滑桿的回彈動畫會短暫低於 0；舊版把此值直接帶入虹彩色相，負數餘數會讓 `Color.hsv` 拋出 `IllegalArgumentException`。現在幾何、亮光相位及透明度都使用有限且有界的視覺輸入。回歸測試採相同的真實彈簧規格，確認舊公式確實拋錯、新公式不會；Android 壓力測試也改為先讓按壓動畫實際前進，再往兩端拖動及放開。原有 8 項介面測試名稱與嚴格結果檢查保留。

海象的原生元件測試加入 49 個預報時刻，連續拖動到兩端及中間；明亮、深色及一般／150% 字體均驗證。資料來源與預報內容沒有改動。

颱風頁標題以整個畫面置中，更新按鈕不再擠壓標題寬度。官方路徑解析放到背景執行緒；西北太平洋海岸線在載入時預先建立多級向量，依畫面尺度選擇最大偏差不超過 0.4 像素的細節，32 倍放大使用原始頂點。可見海岸線合成快取批次，填色與邊線只需兩次繪製；小島保留獨立來源形狀及最小可見標記。國家、周邊海域與小島不改成低解析點陣圖。

雷達原先以單精度計算巨大世界座標，再把畫面位置取整數；高倍率時會跳動。現在先以雙精度算出畫面局部座標，再用連續浮點變換繪製。底圖細節層級加入螢幕像素密度，圖磚以目前可見範圍按需載入；新圖磚逐步加入，舊底圖保留到目前視野載入完成。攝影機更新與控制列重組分開，保留明暗模式、來源標示和快取。

雷達回波仍依 RainViewer 公開來源的 512 像素、最高第 7 級原始觀測顯示；放大不產生新的雨勢資料。底圖與回波獨立載入與縮放。

日月頁改用自身中性卡片，加強暗黑模式的文字與藍色重點對比；未照亮的月面增加可辨識的底色及輪廓，日月位置與出沒計算維持原有演算法。

檢查包含實際原生向量／雷達圖磚繪製、連續小幅拖移、深度縮放、明暗與大字體、滑桿真實回彈、海象時刻切換，以及完整原有 JVM／Python 回歸。原生軟體測試不等於手機實測 FPS；新的 8 項遠端介面結果，以套用後的 GitHub Actions 為準。
