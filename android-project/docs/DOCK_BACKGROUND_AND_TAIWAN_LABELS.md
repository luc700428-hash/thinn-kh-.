# Dock 背景融合、平板氣泡及地名

天氣頁的背景延伸至完整工作區，包含 Dock 預留區與折疊裝置另一側的天氣概覽，取代原有使用淺色系統背景的白色直條。天氣背景保持深色文字對比，因此即使系統為亮色模式，Dock 也會選擇對應的深色透明材質與明亮文字。設定及一般工具頁依原本的明暗主題配色。

Dock 與背景為獨立的擷取層。背景層不包含 Dock 本身，延續既有的防止自身取樣與裁切保護。外框改用單層低強度高光；開啟降低透明度時仍保留實色材質，以維持可讀性。

選取氣泡現在依實際格子尺寸計算，沒有固定 56 dp 的跨軸高度上限；垂直模式以 5 dp、水平模式以 6 dp 作為主軸邊距，與觸控格子的配置一致。頭部與黏著尾部保持相同大小，圖示及文字不旋轉。四個位置、回彈、拖動與取消手勢保留。

「平板 Dock 位置」僅在偵測為平板或折疊裝置時顯示。一般手機即使橫向、視窗很寬，也不出現此設定；平板分割視窗與折疊外螢幕可保留偏好。實際 Dock 排列仍依可用視窗尺寸、鍵盤、鉸鏈位置與字體大小重新配置，空間不足時暫用底部。

裝置偵測沿用 WindowManager、最大視窗尺寸、鉸鏈感測器特徵及曾觀測到的摺痕；沒有依型號建立白名單。依據：[Android 裝置類型與視窗適配指引](https://android-developers.googleblog.com/2023/06/detecting-if-device-is-foldable-tablet.html)。查閱日期 2026-10-31。

## 地名

與台灣相關的外部國名及代表隊別名在顯示邊界統一為「台灣」。涵蓋城市搜尋、反向定位、已存城市、主頁、小工具、天氣通知、離線預報快取與鬧鐘語音快取；舊快取在讀取時清理。非台灣城市的國名與行政區保留，座標、城市 ID、預報及警戒數值不變。釣魚台維持使用者要求的「台灣 · 釣魚台」顯示。

完整驗證數量與畫面以更新包 validation/ 為準。自動化包含原生明暗主題、四邊 Dock、100／150% 字體、書本／桌面摺疊、鍵盤、氣泡與實際觸控格子的對齊、手機設定隱藏、資料及快取地名清理。未宣稱已在所有實機上完成 GPU、音量與鉸鏈感測器驗收。
