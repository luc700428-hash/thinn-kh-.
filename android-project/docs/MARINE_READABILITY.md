# 海象頁閱讀與測站更新動態修正

基底：f6aa22df865504df3ff0d4ad621048d154fb8507（第 305、306 次 GitHub 建置通過的版本）。

海象標題原本位於扣掉右側更新按鈕後的剩餘寬度內，因此偏離畫面中心。現在標題獨立占滿導航列，更新按鈕疊放在右邊。

海域選單原本使用底部面板的預設黑色背景，文字卻沿用明亮主題的深色。現在明確傳入同一組主題的背景與前景，選單跟隨 App 外觀；底部面板也正式套用傳入的內容色、對應把手顏色與 App 的字體縮放，避免新視窗把自訂字體還原。海象卡片使用自身的中性實色背景，次要文字加深；選取海域使用不同底色、勾選圖示及單選語意。選單開啟時先顯示目前海域附近的選項，提供完成按鈕；減少動態時海浪不再啟動持續動畫排程。

測站的每筆新資料原本會取消並重啟約 680 毫秒的亮圈。現在把資料接收與視覺回饋分開：觀測仍立即顯示，僅把確認波圈改成 2.8 秒柔和擴散及 0.6 秒間隔；期間的新更新只保留最新一筆視覺提示。亮圈上限透明度從 0.95 降到 0.36，標題數字不再跟著閃色。減少動態效果時不播放確認波圈。20 秒新鮮度、逐站讀值、真實地震 P／S 波與警報時序未變更。

本機驗證使用真實 Compose 元件、原生 Android API 35 繪製及離線預報 fixture；涵蓋明暗模式、100%／150% 字體、標題中心、文字對比、單選標示、選擇海域、更新與返回。排程測試確認快速資料不會重啟正在播放的波圈，並驗證無效、重複與不符新鮮度條件的更新不觸發提示。

CI 的原有 8 項 Android 介面測試與嚴格結果檢查都保留。修正後的遠端模擬器結果，以套用此包後的新一輪 GitHub 建置為準。
