# 警特報詳情、公告分類與預告時段修正

基底：`afbff54f91351900d4db5fe48ca740bd2bbb2b56`。日期：2026-10-30（臺灣時間）。

## 實際原因

直接檢查中央氣象署 10/30 05:04 左右的官方資料，RSS 同時含有 04:29 陸上強風特報及 04:40 第 074 號顯著有感地震報告。原本的 RSS 入口把這兩類資料都送進天氣警戒地圖，地震報告自然沒有相符的天氣特報內容和縣市警戒範圍。

另一本來已發布的強風特報，其公告影響時段為當日 17:00–23:00。原本的縣市解析器只保留已到開始時間的紀錄，公告詳情的地圖備援也只讀取 `active()` 內容。因此清晨查詢時，已發布的下午預告範圍被丟棄。這些資料不是「已過期」或「查無任何警報」。

## 調整

- RSS 區分地震報告與天氣公告。天氣列表及通知不再混入地震報告；既有「查看官方地震報告」入口直接在 App 內開啟該筆氣象署官方報告。
- 以警特報種類比對詳情，不受 RSS 標題的日期、時間與「發布」前綴影響。
- 保留已發布、尚未開始的縣市特報，傳遞來源開始時間。使用者可明確看到「已發布／預告時段」、「開始時間」、「有效至」及臺灣時間說明。
- 地圖以紅色斜線表示目前生效範圍、琥珀色表示預告時段；同一縣市已有生效警示時，優先呈現生效警示。到期與取消不保留為目前警戒。
- 詳情先呈現名稱、時間與警戒地區，再顯示向量地圖及完整原文，避免整頁只有地圖、重要資訊被推到很下面。
- 三種來源各自完成後立即更新畫面。完整公告讀取失敗時，保留可用的官方 RSS 摘要及重試操作；不把摘要標示為完整原文。無法確認範圍時先呈現文字狀態與摘要，避免空白底圖佔據整頁。RSS 的跳脫換行整理為正常文字。原有 App 內的官方完整頁面與圖表入口保留。
- 詳情狀態、時段與原文使用完整欄寬及明確行高，驗證大字換行。官方頁面的可選深色轉換若發生不支援例外，保留原網頁樣式與閱讀操作，不讓這項視覺功能中斷官方內容。
- 主頁上的預告特報加上「何時起生效」，避免讓使用者誤認已在影響時段內。

## 來源與測試

- [官方 RSS](https://www.cwa.gov.tw/rss/Data/cwa_warning.xml)
- 縣市範圍：氣象署 file API，`W-C0033-001` JSON。
- 完整文字：氣象署 file API，`W-C0033-002` JSON。
- [陸上強風官方頁](https://www.cwa.gov.tw/V8/C/P/Warning/W25.html)
- [氣象署陸上強風產品說明](https://opendata.cwa.gov.tw/opendatadoc/Warning/W-C0033-006.pdf)：區分生效、開始、結束時間與影響區域。
- [AndroidX WebSettingsCompat](https://developer.android.com/reference/androidx/webkit/WebSettingsCompat)：深色轉換需檢查 WebView 支援，未支援可能拋出 `UnsupportedOperationException`。

上述實際回應保存於測試資源 `cwa-warning-20261030/`，僅供固定時間的回歸測試，不放入正式 App 當作現行警報。測試包含凌晨已發布的下午預告、來源開始／到期邊界、取消、來源失敗備援、縣市合併、日期標題比對、地震報告分流，以及明暗模式與 100%／150% 字體的原生 Compose 排版、點選、重試與官方頁面開啟。

地圖仍為縣市層級的公告範圍提示；原文中的沿海、山區、半島與局部地區限制完整保留，不把整個縣市宣稱為精確災害範圍。Robolectric 與本機 APK 建置不代替手機網路、真實 WebView 載入或實機驗收。既有 CI 模擬器回歸、正式版 Lint 與簽章發布檢查保留；實際驗證結果附在交付包 `validation/`。
