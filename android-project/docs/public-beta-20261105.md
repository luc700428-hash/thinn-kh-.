# 2026-11-05 公測前修正與驗證紀錄

本次以 main 的 3e078e00b015d0ad0a84c8868f294525df1e76f2 為基底。這是原始碼候選修正，不是已完成全部裝置驗收的 APK，也未發布正式 OTA。

## 已完成的程式修改

- 平板 Dock 改依四個按鈕及文字大小決定長度，標準文字的橫向尺寸為 296 × 78 dp、直向為 76 × 294 dp；維持右側預設、四邊位置偏好、保留內容空間與既有液態切換效果。
- 地震主頁依 Dock 與折疊安全區之後的可用寬高，切換地圖與觀測面板雙欄或上下排列；保留縮放、圖層與回放狀態，開啟設定不再銷毀主頁。
- 速報畫面加大平板地圖，關鍵所在地震度、抵達估計與震源資料維持獨立面板；地圖縣市色塊仍只使用來源提供的震度。
- 地震設定以完整功能群組重排雙欄；一般、警報、音效、關於採內容尺寸膠囊。大字與窄視窗回復單欄。
- 修正地震日間地圖與狀態文字對比；保留 20 秒觀測時效判定，不把資料過期當成已證實離線。
- 報告更新加入重複請求防護、載入與失敗訊息，保留成功取得的舊資料；離開頁面時正確取消請求。
- 移除設定首頁最底部「自動檢查更新」。軟體更新頁仍可手動檢查；原本的背景檢查僅通知新版本，名稱改成「檢查新版本通知」，不代表自動安裝。

## 緊急速報模式

在「地震監測設定 → 警報 → 鎖定畫面與焦點通知」明確啟用。僅真實、有效且達所在地震度門檻的 EEW 使用緊急模式；震後報告、測站觀測與歷史回放不提升權限。最低門檻 1 級、預設 3 級維持不變。

緊急模式使用鬧鐘音訊，並在使用者授權後請求優先勿擾的通知分類例外。保留既有通知分類的關閉、靜音與音量設定，不調高全域音量、不切換手機鈴聲或勿擾模式、不刪除分類來規避封鎖。連續音效最多 35 秒，取消或關閉速報即停止。

畫面會顯示實際串流連線、通知、App 鎖屏開關、系統全螢幕權限、勿擾存取與鬧鐘音量。提供五秒後的本機通知測試；演練有獨立、不可外部呼叫且 65 秒失效的憑證，明確標示不是現在發生的地震，真實速報優先。

Android 的全螢幕通知在鎖定、熄屏時才可依授權啟動；解鎖操作其他 App 時通常顯示浮動警報。系統完全靜音、使用者封鎖、未授權、強制停止、背景限制或收不到網路資料時，無法承諾送達、發聲或強制蓋上其他 App。這不是政府災防告警系統。

## 必須由 APK 流程通過的檢查

新增 tablet-seismic-regression，執行全套 JVM／Robolectric 測試與 lintRelease，強制要求九個類別共 31 個平板／緊急通知案例有完整成功結果，失敗、跳過、重複或缺失皆拒絕通過。原本 rendering-regression 的八項 Android 裝置測試保持原樣，仍是候選 APK 的必要前置條件。

新增原生畫面測試涵蓋：深淺模式、100%／150% 字體、平板橫直向與分割視窗、Dock 內容邊界、地圖縮放與圖層狀態、雙欄設定、速報關鍵數值與大地圖。新增通知測試涵蓋：明確啟用、保留封鎖及靜音、演練憑證、防偽與期限、取消測試、真實速報中斷演練。

目前這些 Android 檢查尚未在本機執行，須等 GitHub Actions 產生實際結果；沒有以空報告、略過或刪測試方式放行。

## 公測放行仍待確認

候選 APK 必須完成手機、平板、折疊機實機驗收：定位授權與拒絕、斷線恢復、天氣與警特報完整資料、雷達預載與連續拖曳、颱風縮放、海象滑動、鬧鐘及音景、Widgets 同步、Dock 導航、簽章版本與更新安裝。小米／HyperOS 需額外實測靜音、優先勿擾、鎖屏、熄屏、背景與省電狀態的警報行為。
