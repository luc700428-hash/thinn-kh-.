# 連續雷達回放與臺灣警戒地圖

基底：`37919e71e6012b4a9f90d634e996846b81d5bc64`。保留上一輪已通過第 312、313 次建置的功能與全部 8 項 Android 介面回歸檢查。

## 雷達

原介面以整數影格索引啟動網路載入，切換時暫時隱藏舊回波。新版改用連續浮點時間軸；下載工作只依視野、來源時間軸及重試狀態啟動，不依滑桿游標啟動。先取得目前觀測，再預載整段歷史；影像與動態過渡完成後才啟用連續拖曳與播放。缺測時仍保留已顯示的回波，可手動查看已完成時段或重試。

播放以顯示器 frame clock 推進，每段觀測約 1.1 秒，不以螢幕更新率改變播放速度。相鄰影像在背景進行低解析度區塊匹配，將可信的位移套用到原始 512 像素圖塊網格；沒有可信匹配時採用透明度過渡。原始端點與雨量顏色不變，不跨缺測大間距估計位移，也不把最新到最舊的循環當成同一個氣象移動。動畫只是相鄰歷史觀測之間的視覺過渡，不是新增觀測或預報。

每個視野最多保留 4 個不同來源圖塊，低記憶體裝置降為 2 個；最多 18 個觀測影格。圖片、位移網格與顯示中的場景都有界限，逐幀繪製不建立新 Bitmap。新資料尚未到齊時，原場景仍跟隨地圖手勢。尊重減少動態效果與前景生命週期。

沿用圖塊記憶體及磁碟快取，新增同圖塊請求去重、壞檔刪除及每分鐘 90 次的滾動網路預算；快取命中不消耗預算。仍保留 512 像素、來源最高 zoom 7、獨立高清底圖、明暗配色與 144Hz 相容裝置請求。

## 首頁與工具

移除首頁同一玻璃方塊中的「中央氣象署警特報」及「氣象詳解與外出時段」入口。這兩項功能仍從工具頁進入；有效警報的紅色卡片與點選後在 App 內查看詳情的流程保留。

## 臺灣警戒地圖

警特報頁另讀氣象署 W-C0033-001 全國資料，不使用只篩選目前所在地的清單當成全臺資料。必須有完整且不重複的 22 縣市、正式公開狀態、有效發布與生效時間；缺少狀態或時間的資料不當成「無警報」。資料更新失敗、快取、過期公告及不同官方資料更新時間均保留可辨識狀態。全國公告與各別特報分別保留官方發布時間；較舊的全國資料不會蓋掉較新的公告或取消訊息。此頁僅顯示官方公告範圍，不新增 CAP 警報或改變既有地震、海嘯、颱風警報狀態機。

向量圖資由國土測繪中心公開的具名縣市界線產製，保留 22 個縣市、697 個環與 27,597 個頂點，並保留來源雜湊及授權。臺灣本島可縮放、拖移、點選；馬祖、金門與澎湖以有標示的分圖呈現。著色及斜線代表「公告涉及縣市」，不宣稱全縣市或完整行政邊界就是精確危險範圍；沿海、山區及局部地區仍呈現官方原文。向量隨最終尺寸繪製，明暗模式有獨立高對比配色及選取外框。

圖資使用 `.tkatlasz` 名稱保留壓縮內容，避免 Android 資產打包自動解壓並改寫 `.gz` 檔名；測試會從實際打包資產載入，而非只讀開發目錄中的原檔。

- 警特報欄位：https://opendata.cwa.gov.tw/opendatadoc/Warning/W-C0033-001.pdf
- 邊界來源：https://maps.nlsc.gov.tw/download/縣市界線(TWD97經緯度).zip
- 資料目錄與授權：https://data.gov.tw/dataset/7442
- 圖資版本與雜湊：`app/src/main/assets/maps/warning_counties.metadata.json`

## 驗證

新增播放時間、刷新率、預載順序、圖塊預算、缺測操作、請求預算、位移信心及取消工作的測試。原生繪圖測試使用已知位移的合成回波，檢查中間位置、透明度與舊邊緣殘影；另使用實際相鄰臺灣回波與 OSM 圖塊驗證日夜合成及來源端點。

地圖測試涵蓋官方樣本、全國／所在地清單區別、缺漏／重複縣市、無效時間、取消、來源不同步、過期、具名向量、離島、縮放點選及日夜配色。Compose 測試另以 100%／150% 字體檢查對比、標題裁切與唯一選取狀態。

本機原生 Android 測試使用 Robolectric API 35，不等同 Android 模擬器或使用者手機驗收。實際幀率、耗電及手機手勢仍需在新建置安裝後確認；完整 Android 8 項介面門檻與正式簽章流程維持原樣。
