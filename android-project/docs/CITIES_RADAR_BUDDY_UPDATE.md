# 地點搜尋、App 內雷達與 Q 版天氣夥伴

本次改動接續 V25 已有 20 款天氣流行鬧鐘、27 款重製小工具與共用玻璃介面；新增 Q 版夥伴後共 28 款。

- 主頁：長條搜尋，移除上方健康檢查與手動更新鍵；下拉觸發更新。健康檢查仍可從設定使用。
- 搜尋：離線鄉鎮先顯示，280ms 停頓後查詢全球服務；取消舊查詢並以代數檢查避免舊回應蓋掉新結果。常用與最近地點可離線搜尋，支援完整地區名稱、英文及座標。釣魚台的台灣顯示規則限定於島群座標，不會把北京同名地點重新命名。
- 雷達：原生 Compose 地圖與 Mercator 投影，RainViewer 歷史回波、OSM 底圖，最高縮放 7。近兩小時通常有 13 張回波，實際以供應者回傳為準。圖層合成時間不等於每個雷達像素的觀測時間。資料不足、服務中斷與部分圖磚失敗均明示。
- 快取：只請求使用者正在看的視窗，最多四個並行請求；底圖快取至少七日，歷史回波快取三小時，圖檔先檢查尺寸再解碼。記憶體圖檔上限 12MiB，磁碟定期修剪至 48MiB，無區域預抓功能。
- 環境音：新增晴天、多雲白天、多雲夜晚與晴夜循環；晴天同名音軌取代原版本。原創合成，沒有取用第三方錄音；未宣稱人耳聽感評分。
- 天氣用語：集中解讀 WMO 代碼。毛毛雨與雨分別保留強度，夜間、雪、霧、冰雹與凍雨也有對應詞；沒有有效強度資訊時使用「降雨」，不臆測大雨。
- 滑桿：透明鏡片由同一個 Canvas 畫出，無 RenderNode 捕捉或可變 RuntimeShader；保留彩邊、黏著水尾、回彈及無障礙進度操作。這是對已確認高風險生命週期的修正，沒有取得使用者手機的崩潰堆疊，不能宣稱所有閃退原因皆已重現。
- 字體：共用文字包裝套用字重與字型；根密度統一處理 100–150% 文字縮放，巢狀主題不重複相乘。字體滑桿在放手時提交設定。
- Dock：選取鏡片維持相同大小，加長水尾追隨，加入彩色邊光；地震三個分頁和主導航共用元件。

## Q 版小工具的動畫方式

原創 Android Canvas 向量角色會依天氣、日夜切換；未知天氣使用中性角色，不冒稱晴天。桌面端 ViewFlipper 播放閉合的漂浮、呼吸光、24 格眼神與 24 格雨滴／水花時間軸；落雨與水花共用相位。每次天氣更新、按下重新整理或設定中的「換個表情」會取得新動作種子。漂浮容器只有一個子頁，因此切換不會重置眨眼。

角色位圖限制尺寸，動畫單卡角色位圖總量以測試限制在 4MB 以下。沒有每幀喚醒 App 的服務。桌面是否支援連續播放及實際幀率由啟動器與系統決定，未宣稱使用 Apple 私有動畫引擎或保證 120FPS。

- 代表座標與別名：GeoNames，CC BY 4.0，https://www.geonames.org/ 與 https://download.geonames.org/export/dump/ 。座標是地區代表位置，並非門牌或 GPS。
