# 臺灣雷達細節、921 情境演練與外出穿搭

基底：`b329aeea86524e0d9af9f87f579d7bd25cb47240`。

## 雷達

RainViewer 的免費圖磚自 2026 年起最高為 zoom 7；街道底圖放大不能增加回波的觀測細節。本次臺灣區域預設改讀氣象署公開時間索引 `https://www.cwa.gov.tw/Data/js/obs_img/Observe_radar.js` 中實際列出的 `CV1_TW_3600_yyyyMMddHHmm.png`。不猜未發布檔名，不使用私人金鑰。全球雷達保留原來源及請求限制。

原圖 3600×3600、經緯度等間隔：118–124°E、20.5–26.5°N。這是經緯度網格，不可直接當成 Web Mercator 圖磚。解碼器以區域解碼讀取原始像素，再逐像素投影到畫面所需的圖磚。以圖中自己的 dBZ 色標精確識別回波色，灰階海岸線、格線、印刷文字、雷達狀態燈、標誌及色標本身不當成雨區。原圖的印刷遮蓋區不構成可用觀測，空白不解釋成無雨。

這不是數值格點的額外觀測，也不是超解析度生成。原圖像素較細，但物理雷達解析度、觀測盲區與圖面文字遮蓋仍是限制。臺灣模式將操作上限設在 zoom 9；全球模式仍保留原有獨立底圖縮放。日夜模式只改底圖，回波顏色不做夜間色彩轉換。

整段歷史圖先下載並存入有上限的磁碟快取；移動或放大從已存原始圖重新解碼所需區域，時間軸本身不發出逐格網路請求。保留既有觀測間影像位移過渡、無匹配時淡入淡出、減少動態效果與生命週期暫停。每次最多四份 512px 圖磚／觀測，原始圖以區域解碼，不常駐十三張 3600px 位圖。

公開原始資料與測試快照、時間、SHA-256 列於 `app/src/test/resources/cwa-radar-hd/sources.json`。來源範圍可核對氣象署 O-A0058 說明：https://opendata.cwa.gov.tw/opendatadoc/MSC/A0058.pdf 。RainViewer 限制：https://www.rainviewer.com/api/transition-faq.html 。

## 921 演練

官方原始第 043 號報告：https://scweb.cwa.gov.tw/special/19990921/1999092101471273043.htm 。震源為 1999/09/21 01:47:15.9（臺灣時間）、23.85°N、120.82°E、深度 8.0km、芮氏規模 7.3。保留歷史縣市最大震度舊制 0–7；舊制 5、6 級不擅自轉成現制強弱，未列示的地區維持缺值。

使用與正式速報相同的 `SeismicWarningOverlay` 全螢幕 Dialog，含防災動作、震央、波圈、所在地標記、規模與深度。Dialog 不因點擊視窗外圍消失；結束按鈕、返回手勢與關閉按鈕仍可立即結束。演練最長兩分鐘，App 進背景即結束本機演練；正式有效速報可取代演練。

開頭語音：收到地震速報、慎防強烈搖晃，隨即聲明是 921 情境演練。獨立本機演練音訊遵守靜音與勿擾，不建立真實通知，不寫入現行速報串流、歷史報告或推播。這是依歷史震源模擬現代介面，不宣稱重建 1999 年曾經發出的即時預警。

所在地使用手機已有有效定位或使用者自選縣市，不自動指定臺北。演練專用 PGA 簡化關係：`1.657 × exp(1.533 × ML) × r^-1.607`，r 為震源距離，場址係數固定為 1。係數可核對內政部建築研究所《智慧全人居家預警防系統之研究》2023 年報告印刷頁 136：https://ws.moi.gov.tw/001/Upload/404/relfile/9489/277499/ae0080fb-b526-4ab8-8d6c-cd9261f37839.pdf 。

未納入斷層破裂與場址效應；沒有 PGV，PGA 達 80 gal 的模擬區只寫「5弱以上」，不提供虛假精確的現制強弱震度。此模型只用於帶有本機演練標記的情境，正式速報仍只呈現來源提供的縣市震度，不以此模型補值。現制原理：https://edu.cwa.gov.tw/PopularScience/ec/ec_21.html 。波圈仍是示意，不當成真實倒數或到達預測。

## 今天出門

移除使用者自架 Ollama／輸入網址與模型的介面和 HTTP 推論客戶端。穿搭直接在本機依天氣與偏好產生，沒有外部模型、帳號、付費或伺服器連線步驟，也不把規則引擎稱為 AI。

首頁直接列外套要不要帶、上身／下身、鞋襪、雨具與出發／回程時段提醒；保留休閒、運動、通勤、戶外情境。未來六小時低溫與體感會提早觸發保暖；低於 21°C 帶外套、低於 10°C 完整保暖、低於 4°C 加強頭頸與四肢。這些是個人提醒門檻，不是官方低溫特報。怕熱或運動偏好不會取消低溫提醒，亦不建議低溫穿短褲。

雨具依未來時段與設定門檻選擇，機車通勤優先雨衣，強陣風避開撐傘。舊資料與缺少逐時預報會明確提示，沒有資料不當成不下雨。偏好透過本機狀態更新，儲存後首頁立即重算；舊推論網址、模型及啟用值會在開啟偏好頁時移除，原本出行情境繼續沿用。

保暖內容參考國健署多層穿搭、頭頸及四肢、防風防水與運動後乾衣原則：https://www.hpa.gov.tw/Pages/Detail.aspx?nodeid=127&pid=17769 。

## 驗證

新增真實 CWA 圖像解碼／投影對位／回放原生繪製、921 歷史參數／演練隔離／語音與全螢幕介面，以及外出建議／偏好儲存／日夜和 100–150% 字體檢查。使用專案原有 JVM/Robolectric、Python 與編譯工具；沒有新增正式執行期依賴。

Robolectric 4.16.1 尚未提供真正的 BitmapRegionDecoder 像素解碼（只回傳空白區域）。回波原生測試因此以原生 BitmapFactory 解碼真實 PNG、以裁區讀取介面取代此 OS 轉接層；正式投影、色標判定、動畫和繪製程式照常執行。裝置端區域解碼仍需新 APK 的 Android 驗收，並未把空白測試圖當作通過。

原有八項 Android 介面測試、嚴格測試結果檢查與簽章發布流程保留。實際通過數與完整紀錄由更新包 `validation/` 提供；本機原生繪製測試不代表手機的喚醒權限、TTS 聲音或實際 144fps 已驗收。
