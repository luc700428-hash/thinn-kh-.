- **首頁颱風動向入口**：在天氣主頁的官方特報區附近加入颱風資訊入口；有官方公告才顯示公告數，預測路徑導往中央氣象署官方資料，不製造假路徑。

重要：並非全臺高精度 3D 地標、即時官方地震預警、完整官方颱風原生路徑或與 iOS 27 完全一致的外觀已完成。此版是工程候選，須先經 GitHub Actions 編譯、APK 同簽章檢查、實機操作與長時間監測測試；未完成驗收前請勿發布正式 OTA。

# thinn-khì 第 23 代｜大型功能與介面修正版（v23）

本版為全新主要版本 **23**。OTA 安裝包採 `23.0.<GitHub Actions 執行編號>` 作為可唯一識別的版本字串，APK 使用遞增整數 `versionCode`；兩者均高於既有 v22，以確保 Android 覆蓋安裝相容。

## 本次已納入的程式修改

- **地震頁避開手機狀態列**：監測與設定頁加入 Android 狀態列／導航列安全區；地震警示、回放及資訊排版沿用深藍液態玻璃視覺。
- **改善返回手勢**：在設定、工具、事項、警報、更新中心等子頁面優先關閉當前畫面；非首頁分頁返回天氣首頁，不再直接要求關閉 App。
- **地震即時速報專屬前景畫面**：有有效且仍在時效內的第三方速報時，呈現震央、規模、深度、所在地震度（來源有提供時）、臺灣及離島示意位置，以及大字「趴下、掩護、穩住」；無法驗證抵達秒數就不顯示假的倒數。
- **歷史回顧明確區隔**：歷史資料的模擬預警以專屬畫面標示「回顧／模擬」，不可誤認為現在發生地震；原有預警聲、語音與通知選項持續受 Android 系統權限約束。
- **地圖補充離島**：在原本臺澎金馬基礎上加入蘭嶼、綠島、小琉球、龜山島、基隆嶼及釣魚臺列嶼的示意輪廓，使用同一座標系；這不是可供測繪的官方海岸線。
- **地震音效試聽**：在音效資源播放失敗時顯示明確提示，不再靜默無反應。未驗證的測站震度自動檢知仍禁止啟用。
- **中央氣象署特報優先**：首頁多則官方公告排列於「現在最重要的天氣」之上；修正背景警報檢查忽略一般「嘉義縣／高雄市」地名的條件。
- **颱風中心入口**：工具及設定新增颱風動態頁，列出所在地匹配的官方 RSS 颱風公告，並可直接查看中央氣象署的官方路徑與預測頁。不以自製曲線冒充官方資料。
- **工具／設定重新分類**：把事項、鬧鐘、天氣定時通知集中；地震與颱風獨立為安全類別，更新中心與系統健康檢查屬維護類別。
- **天氣鬧鐘**：可新增、編輯、刪除、啟用／停用、選擇日期重複、滾輪選擇時間、稍後提醒 10 分鐘與響鈴頁；可在開啟響鈴頁後朗讀近三小時內取得的天氣與穿衣、雨具提醒，過期資料不會被當作即時天氣。
- **地標自動同城巡遊**：在使用者定位的縣市／島嶼範圍內輪換既有地標，不必手動切換；開啟減少動態效果時停止自動動畫。模型無完成資產時顯示清楚的未建模狀態。
- **移除多餘首頁區塊**：移除首頁「降雨實況與三小時預報」大型方塊；保留 24 小時天氣曲線、重要數據和其餘雷達資料程式。
- **穿搭資訊整理**：先前「穿搭」長文仍然收斂為直接可見的出門建議；完整依據在個人偏好設定呈現。
- **介面一致性**：延續既有 Material3 + Liquid Glass 共用卡片、滑桿、切換控制、動畫與觸感基礎。
- **真正的原始碼 OTA**：GitHub Actions 必須直接編譯儲存庫的 `android-project/`，驗證 APK 來源指紋、版本碼與既有正式簽章；發布最新 Release 的 `ota.json`。

## 重要限制／尚未完成或尚待實機驗收

- **本更新不是全部 14 項完整通過實機驗收的宣告。** 尚未完成全臺每個縣市、外島及國際景點的高精度 GLB 建模，也尚無真正的 Filament 即時 3D 與飛越轉場。現有 17 個獨立 GLB 原型只是原創幾何原型與預覽。
- **第三方地震資訊不可替代官方 PWS**；若缺少可信預估抵達時間，沒有「震波幾秒抵達」功能；無法保證鎖屏全螢幕顯示、音效與即時推播送達。
- **Firebase 推播要由管理員部署後端與設定公開專案識別碼**。若未配置，App 會告知無法接收而不冒充啟用。震後報告為系統定期查詢，非發布瞬間可靠送達。
- 颱風警報更新使用 Android WorkManager（最短約 15 分鐘、可能延後），**不是秒級即時**；未整合官方機器可讀颱風預報路徑資料。
- Android 14+ 精確鬧鐘與全螢幕通知需要使用者授權，拒絕時可能延遲或只能透過通知開啟響鈴畫面。語音依系統 TTS 安裝與可用性運作。
- 介面以 iOS 互動原則重新設計，但不是 Apple 官方 iOS 27，無法保證完全相同特效；動畫、觸覺、對比與各手機尺寸仍待 Android 實機與無障礙驗收。

只有在 GitHub Actions 編譯、APK 簽章與安裝測試通過後，才能發布正式 OTA。舊版 ZIP 成功上傳不代表功能已更新。
