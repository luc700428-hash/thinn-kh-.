# 平板、橫向與可調整視窗版面

這是同一個 Android App 的通用更新，不另製固定比例的平板 APK。以目前 App 視窗的可用寬、高（dp）和使用者字體大小重新排版，不用機型名稱、像素解析度或固定 4:3／16:10 判斷。平板旋轉、分割畫面、摺疊與桌面視窗改變大小時重新計算。

## 版面規則

| 可用空間 | 配置 |
| --- | --- |
| 寬度小於 600 dp | 手機／窄分割視窗：單欄、可捲動內容 |
| 600–839 dp | 中型視窗：限制閱讀寬度，群組依字體與剩餘寬度決定欄數 |
| 840 dp 以上且高度至少 480 dp | 天氣及地震資訊可雙欄，各欄獨立捲動 |
| 字體放大至 150% | 雙欄門檻提升至 1140 dp，每欄預留更多閱讀空間 |
| 高度小於 480 dp | 天氣／設定回到單欄捲動，避免短視窗塞入兩個狹小欄位 |

分欄依可用內容寬度計算，因此加入頁面邊界後可能採較保守的單欄。工具及設定群組每欄至少保留約 320 dp，字體放大會同步增加需求；最多兩欄。閱讀頁面最多 1120 dp、工具與設定最多 1280 dp，避免將文字與按鈕拉滿大螢幕。

## 已調整畫面

- 天氣：目前天氣、地點與警示在前欄；預報、外出建議與天氣指標在後欄。單欄保留原順序。
- 地震：測站圖與觀測／報告分欄；速報地圖與所在地震度、抵達時間分欄，避難及關閉操作保留固定位置。
- 工具與設定：群組自動排列，搜尋仍作用於同一份內容；設定項目維持可辨識的點擊範圍與文字行高。
- Dock：維持原本液態玻璃互動，限制整體寬度並置中，不將四個分頁拉到平板兩側。
- 雷達：地圖維持 1:1；寬視窗與中型短橫向視窗把播放、時間軸、資料源與透明度放在右側，窄視窗改成上下捲動；限制窄視窗地圖高度，確保能從操作區捲動，不被地圖拖曳手勢困住。地圖尺寸改變時同步更新相機及手勢座標。
- 地圖詳情：颱風與警戒範圍依可用高度調整；向量圖、時間軸與資料來源處理沿用現有功能。
- 時間等共用表單：大型視窗使用有限寬度的置中浮窗，小型視窗保留底部表單；高度依當下可用空間與鍵盤縮減。
- 鬧鐘：大型畫面的停止／稍後提醒控制有最大寬度；極短橫向畫面將時鐘與控制分開排列。
- 其他全視窗詳情、城市搜尋與首次啟動引導：使用適合閱讀的寬度；雷達、速報及時間表單自行管理完整視窗。

## 視窗改變時的狀態

主 Activity、地震警報 Activity 及鬧鐘 Activity 明確支援調整尺寸，並由 Compose 處理 orientation、screenSize、smallestScreenSize、screenLayout 的組態變更。沒有鎖定方向、固定長寬比或以 Android 16 相容模式躲避調整尺寸。

`AdaptiveWindowProvider` 從實際有界的版面取得 dp 尺寸；`movableContentOf` 移動既有分欄內容，因此切換斷點不重新建立搜尋與滑桿狀態，不因搬到另一欄重啟該內容的載入工作。Wi-Fi 平板不必具備 GPS 或行動網路定位硬體，仍能使用城市搜尋。

這些組態變更不取代一般 Android 行程重建、系統權限或背景服務限制，亦沒有改動地震警報的觸發門檻、通知權限、全螢幕授權與安全交付流程。

## 驗證

新增原生 Robolectric API 35 渲染與互動測試，涵蓋 480×800 分割視窗、600×960、768×1024、800×1280、1024×768、1280×800、1600×1000，以及 480／600／800／1280×360 和 1280×400 的短橫向視窗；明亮／深色與 100%／150% 字體組合依畫面分別驗證。

測試實際重新量測同一個 Compose 視窗，檢查搜尋內容、滑桿值、地震設定選擇是否保留、元件是否超出邊界、工具動作與速報關閉是否作用、雷達是否正方形。保存原生渲染 PNG 供檢查；不是 Android 模擬器或實體平板驗收。

原有 8 項 Android 裝置介面回歸、嚴格結果檢查、Release Lint 與 GitHub 既有簽章流程維持。此更新包預設只觸發候選 APK，不代表已發布正式 OTA。
