# thinn-khì V15.1 臺灣地震專屬設定中心

- 設定入口：臺灣即時地震監測頁右上角齒輪，或監測頁中段「開啟設定」。
- 「一般／警報／音效／關於」四分頁；Android SharedPreferences 記住逐項偏好。
- 9 段短促原創 OGG：3 段速報（初報、來源明確緊急、同事件更新）、5 段測站檢知試聽與 1 段震後報告。
- 真正已連動的訊息來源：ExpTech EEW 初報／新報次、公開震後地震報告；緊急需原始資料明確註記。
- 5 種測站檢知類別目前只提供試聽，開關鎖定，沒有可靠震度／gal 解析前不對外送出測站檢知警報。
- 報告來源：ExpTech DPIP /api/v2/eq/report；不再要求一般使用者自己填寫 CWA 授權碼。若網路錯誤或資料欄位變動，明確顯示查詢失敗，不假裝無地震。
- Android 8 以上音效由通知通道管理，App 只在尚未建立時設定，不覆寫使用者的系統個別分類偏好。
- 原有 8 款一般通知音、地震演練、地震警示及 OTA signing Secrets 不變。
- 尚未驗證完整 Android 編譯或實機 ExpTech API schema；正式公開使用前須測試。
