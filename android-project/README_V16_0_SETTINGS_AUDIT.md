# thinn-khì V16.0 設定功能稽核測試版

此版本針對 V15.4 已存在的設定功能修正與狀態可見性，而非聲稱所有系統級能力皆可強制啟用。

- 智慧天氣時分輸入改為 Material3 觸控拖曳錶盤，保留星期多選、最多五組、儲存及排程。
- 偏好設定新增「檢查設定是否真的生效」，檢查通知與定位授權、版本更新定期工作、五組智慧通知背景排程、地震前景串流狀態。
- 自動更新檢查開關同步註冊／取消 WorkManager 工作，不再只存偏好值。
- 地震設定預設顯示「一般」頁，先揭露 EEW／RTS 實際連線狀態。保留真實地震警報權限限制與禁用未驗證測站偵測。
- 保留 V15.4 的所有其他功能與簽署方式。

未完成：全 APP 的液態玻璃全面覆蓋、全面重新設計地震第二頁、所有小米焦點通知上島、地震即時資料實機可靠性認證、完全準時的智慧通知。這些功能需要後續開發／實測，不應被當成已修復。
