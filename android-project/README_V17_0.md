## 資安警告
此次依使用者要求把 CWA 授權碼內嵌。任何人都可能從 APK 或 GitHub 公開碼取出，不能視為密鑰保護。建議正式釋出前，改由伺服器保管、設定呼叫額度並輪替。

## 發布建議
只以 `publish_release=false` 進行測試建置，確認操作、定位、通知、警示與資料真實性後才評估正式 OTA；未驗證地震警示不宜廣泛推送。
