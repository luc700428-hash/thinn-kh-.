# thinn-khì V11.3 — 八款自選通知音

- 在偏好設定新增八款音效：清鈴（預設）、水晶、晨光、雨滴、星點、微風、晴空、漣漪。
- 每款均可獨立試聽；點選單選列即儲存偏好，重啟 APP 後仍會保留。
- 天氣警特報、版本更新、焦點通知測試及一般測試通知皆經 `ThinnNotificationChannels.channelId(context, Type)` 選擇通道。
- Android 8+ 通知音效與通道 ID 綁定：預設「清鈴」沿用 V11.2 的舊通道與既有使用者設定，其餘 7 款使用獨立 `..._tone_v3_...` 通道；切換音效後的新通知會使用對應通道。
- 只會建立目前所選聲音的通道；不會刪除既有 Android 通知通道，也不會嘗試繞過靜音、勿擾或使用者自訂聲音。
- 通知通道可能被使用者或廠牌系統靜音，APP 不保證每則通知皆能播放聲音。
- 保留 V11.2 天氣、Widget、氣象警特報、焦點通知優先與 GitHub OTA 簽署功能。
